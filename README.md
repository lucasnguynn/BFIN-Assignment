# BFIN Kappa Member 2 — pinned GitHub yfinance retrieval and analysis

This package integrates the previously tested Member 2 M2-02/M2-03 code with an **official GitHub-source installation** and an **optional GitHub Actions workflow**. The workflow should be added to a GitHub repository under your control, not the yfinance upstream repository. It retrieves Yahoo Finance historical prices at runtime using yfinance.

Start with `docs/GITHUB_ACTIONS_SETUP.md`. The analysis tests use synthetic fixtures only; **all actual investment evidence must come from successfully archived Yahoo data**. The proposed twelve-security universe, risk aversion, weights, and benchmarks are not approved investment decisions.
